I made a plugin that allows SayoDevices that are modded with O3Cpatch to be controlled via SignalRGB! Works with base O3C, but I don't know if anything is different with the O3C++. Tested on CachyOS (I don't believe any udev rules are required) but untested on Windows and other Linux operating systems (it should work fine). It would be great if anyone with a patched SayoDevice would give it a try!

https://github.com/slinkybuky/o3c-signalrgb

Known limitations: Only the left 2 of 3 lights work at the moment. This is an O3Cpatch issue, not a plugin issue. I might make a PR to O3Cpatch sometime soon, but don't be caught off-guard if the right one doesn't work.

Disclaimer: If you are going to patch your O3C, make sure you use the correct O3Cpatch version for your firmware. The latest patch version can be found at https://o3cpatch.pages.dev/ and applied using developer mode at https://sayodevice.com.
